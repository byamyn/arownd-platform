## 3. شروط «Label Startup» (مرجع — للترقية لاحقًا)
من https://startup.dz/pour-les-startups/:
1. **العمر:** الشركة ≤ 8 سنوات.
2. **الابتكار:** نموذج الأعمال يعتمد على منتجات/خدمات **innovants** (创新 non nécessairement technologique: architecturale/disruptive/radicale).
3. **النمو:** إمكانات نمو importante.
4. **الإيرادات:** CA annuel ≤ plafond fixé par le comité national.
5. **الرأسمال:** ≥ 50% مملوك لأشخاص طبيعيين / صناديق استثمار معتمدة / شركات ذات label Startup.
6. **الحجم:** ≤ 250 موظف.

> ملاحظة: هذه الشروط خاصة بـ «startup» (شركة). لـ «projet innovant» (مشروع قبل الشركة) لا تُذكر شروط كمية على الموقع؛ eligibility تُحدَّد من طرف Comité de labélisation. **TODO:** تأكيد مع لجنة/حاضنة.

## 4. حقول طلب «Label projet innovant» (من النموذج)
### A. معلومات مقدّم الطلب
- NIN (رقم التعريف الوطني)
- اللقب/الاسم، العمر (0–100)، الجنس
- هاتف 1/2، بريد إلكتروني
- مستوى التأهيل (Technicien … Doctorat / Autres)
- الصفة (Fondateur unique / Co-fondateur / autres) + أسماء/مستويات المؤسسين الآخرين
- CV للمؤسسين (≤ 200 MB)
- Wilaya (58)، عنوان، residence à l'étranger? pays
- Facebook/YouTube

### B. معلومات المشروع
- Nom du projet
- Secteur d'activité (قائمة: Fintech, Cloud/SaaS, Agritech, Biotech, Greentech, Logistique, E-commerce, Edtech, Govtech, Legaltech, Food tech, E-health, Smart City, IoT, Big data, Tourisme, Energies renouvelables, Pharma, Education, IA, AR/VR, E-services, Économie sociale et solidaire, Cybersecurity, Électronique, Jeux/loisir, AquaTech, Oil & Gaz, Autre)
- **Description courte (≤ 400 caractères):** «Décrivez … votre projet et pourquoi il est innovant»
- **PitchDeck** (pdf/pptx, ≤ 200 MB) — **يجب إعداده وفق Canevas (القالب)** — رابط تحميل في النموذج
- **Présentation détaillée** (aspects d'innovation) — pdf/pptx
- **Photo du prototype** (≤ 200 MB)
- Avancement: Concept/Idée | Prototype en développement | Prototype prêt | Produit prêt
- Type de modèle économique: B2B / B2C / B2G / Autre
- Site Web
- Accompagnement par incubateur? (Oui/Non) + type (Privé/Public) + inscrit selon décision ministérielle n° 1275? (Oui/Non) + attestation d'incubation (≤ 200 MB)
- Propriété intellectuelle? (Oui/Non) + type (Brevet/Marque/Design/Droit d'auteur/Autre) + document justificatif (pdf/jpg, ≤ 200 MB)
- Site web / Concours-récompenses
- Acceptation مشاركة المعلومات الشخصية

> ملاحظة: «Prière de remplir tous les champs en lettres latines uniquement» — كل الحقول بالأحرف اللاتينية فقط.

## 5. قالب Pitch Deck (12 شريحة) — Canevas
1. **Présentation générale:** Titre, Logo, Tagline, infos contact (nom, fonction, email, téléphone, site web, réseaux).
2. **Résumé du projet:** Problématique + solution + impact (clair/concis/percutant).
3. **L'équipe:** Membres (nom/prénom/profil), compétences, rôle.
4. **Problématique ciblée:** données chiffrées/études de cas + visuels.
5. **Solution proposée:** originalité + efficacité.
6. **Présentation du prototype (produit/service):** lien prototype/vidéo (≤ 4 min pour prototypes matériels), lien APK (Android/iOS), lien site web.
7. **Brevets, marques et droits de PI:** brevets déposés/en cours, marques/designs enregistrés, droits d'auteur/licences.
8. **Valeur ajoutée:** gains pour clients (temps, économies, innovation, impact environnemental…).
9. **Analyse concurrentielle:** concurrents directs/indirects, SWOT, différenciation (pourquoi meilleure/unique).
10. **Analyse du marché cible:** cible principale (clients/utilisateurs/bénéficiaires).
11. **Modèle économique (business model):** génération de revenus + rentabilité.
12. **Roadmap du projet et stratégie de développement:** étapes clés (tech/commercial/expansion), objectifs 6 mois / 1 an / 3 ans, ressources (humaines/financières/techniques).

**الشريحة 13:** Merci.

## 6. مزايا علامة «projet innovant» (من الموقع)
- exonérations fiscales (incubateurs: 2 ans — LF 2021) — للمشاريع: «mêmes avantages que label startup».
- financement (ASF — Algerian Startup Fund) للشركات ذات label.
- foncier (facilités) — للحاضنات.
- accès aux programmes (Algeria Disrupt, A-venture, meetups).
