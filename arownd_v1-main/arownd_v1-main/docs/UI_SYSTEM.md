# Arownd — نظام الواجهة (Premium UI System)

مرجع عمل لكل شاشة جديدة أو معدَّلة. الهدف: واجهة هادئة، سريعة الفهم، متسقة، وتعمل بالعربية RTL أولًا.

## 0) الاتجاه التصميمي: Hybrid Premium
واجهة فاخرة هجينة تجمع ثلاثة أساليب في لغة واحدة متناسقة:

| الركيزة | المعنى في Arownd | قواعد التنفيذ |
|---|---|---|
| **Minimal Premium** | بساطة، أناقة، مساحات مريحة | إجراء رئيسي واحد لكل شاشة؛ مسافات بمضاعفات 4px؛ هامش جانبي `px-4`؛ لا زخارف بلا وظيفة؛ حدّ رقيق + ظل ناعم فقط |
| **Neo Luxury** | فخامة، ألوان متناسقة، حركة ناعمة | لوحة العلامة فقط (الليموني `--primary` + حبر `--accent-ink` + محايدات)؛ حركة موحّدة عبر `--ease-premium` و`--dur-fast/base/slow` (150/220/360ms)؛ رفع خفيف عند المرور لأجهزة المؤشر فقط؛ تُحترم `prefers-reduced-motion` |
| **Smart Discovery** | اكتشاف قريب، بحث ذكي، مقارنة أسعار | وسوم `tag-smart` مشتقة من البيانات الفعلية فقط (أفضل سعر، الأقرب)؛ الترتيب الافتراضي: المتوفر أولًا ثم الأرخص؛ المسافة تظهر عند توفر الموقع؛ عرض التوفير مقابل أعلى سعر |

### أدوات النظام الجديدة (في `styles.css`)
- `card-premium`: سطح بطاقة موحّد (حد، ظل، رفع خفيف، ضغط). مطبّق على بطاقات المتاجر والعروض.
- `tag-smart`: وسم اكتشاف صغير بلون العلامة الناعم.
- رموز الحركة: `--ease-premium`, `--dur-fast`, `--dur-base`, `--dur-slow`.

### الاكتشاف الذكي — الحالة
- ✅ صفحة المنتج: وسما «أفضل سعر» و«الأقرب إليك» وسطر التوفير داخل قائمة المقارنة (تظهر فقط حين يوجد أكثر من عرض متوفر وفارق حقيقي).
- ⏳ غير منفّذ بعد: مقارنة جنبًا إلى جنب لمنتجات مختلفة، وسوم الاكتشاف في بطاقات الاستكشاف، ترتيب «الأقرب» الافتراضي عند منح الموقع.

### الفرض الآلي
`npm run ui:check` (أو `node scripts/ui-lint.mjs`) يكسر الفحص عند: اتجاه فيزيائي، اسم علامة خاطئ، حوار متصفح أصلي، لون hex داخل className، صورة بلا alt، زر أيقوني بلا اسم. التحذيرات (نصوص ثابتة في الخصائص، lazy للصور، autoComplete) دَين تقني يُعرض بـ `--verbose`.

## 1) المبادئ
1. **وضوح قبل زينة:** إجراء رئيسي واحد في كل شاشة (`btn-primary`)، وما عداه `btn-secondary`.
2. **قابلية الوصول للإبهام:** أهداف لمس ≥ 44px، الإجراءات الحاسمة في النصف السفلي (StickyActionBar).
3. **كل حالة مصمَّمة:** تحميل (Skeleton) · فراغ (EmptyState) · خطأ (ErrorState + إعادة محاولة) · نجاح (toast) · تأكيد (confirm-dialog) للعمليات الهدّامة.
4. **لا نجاح زائف:** لا نعرض نجاحًا قبل تأكيد الخادم؛ الأزرار تُعطَّل أثناء الإرسال (ref + state).
5. **حركة قليلة:** انتقالات 150–250ms فقط، وتُحترم `prefers-reduced-motion`.

## 2) الرموز (Tokens) — من `src/styles.css` فقط
- الألوان: `bg-background`, `bg-card`, `text-foreground`, `text-muted-foreground`, `bg-primary`, `text-accent-ink`, حالات: `success/warning/danger(-soft)`. ممنوع الألوان الحرفية (#hex).
- الزوايا: 8 / 12 / 16 / 20 / pill (`rounded-xl` للحقول والبطاقات، `rounded-2xl` للبطاقات الكبيرة، `rounded-full` للشارات).
- الظلال: `shadow-soft` (بطاقة) · `shadow-lift` (شريط/قائمة) · `shadow-pop` (نافذة).
- الخطوط: `text-display / h1 / h3 / section / body / caption / price` (مقياس موحّد).
- المسافات: مضاعفات 4px (`gap-2/3/4`, `px-4`, `space-y-3/4/6`)، هامش جانبي ثابت `px-4`.

## 3) RTL/LTR
- استخدم خصائص منطقية: `ms-/me-`, `ps-/pe-`, `text-start/end`, `start-/end-` بدل `ml/mr/left/right`.
- الأسهم والأيقونات الاتجاهية: `rtl:rotate-180` أو `ltr:rotate-180`.
- لا تقرأ `document.dir` في الرسم؛ استخدم `useTranslation().isRTL`.

## 4) النصوص
- لا نص ثابت داخل JSX/`aria-label`/`placeholder`/عناوين `head`: استخدم `t("key")` (أو `translate` في `head`).
- المفتاح في المجموعة الأقرب للشاشة داخل `src/lib/dictionaries/` بالعربية والإنجليزية معًا (اختبار التكافؤ يفشل إن غاب أحدهما).
- الأرقام والتواريخ عبر `formatDA` و`formatDate` فقط.

## 5) الشاشات والمكوّنات
| الحاجة | المكوّن |
|---|---|
| هيكل الصفحة | `AppShell` + `PageHeader` |
| بطاقة منتج/متجر | `ProductCard` / `StoreCard` |
| حالة المخزون/الفتح/التوثيق/الطلب | `StockBadge` / `OpenBadge` / `VerifiedBadge` / `OrderStatusBadge` |
| شريط إجراء سفلي | `StickyActionBar` (والمحتوى `pb-[calc(11.5rem+env(safe-area-inset-bottom))]`) |
| لوحة سفلية | `bottom-sheet` (`role="dialog"` + `aria-modal`) |

## 6) قائمة فحص قبل الدمج
- [ ] ثلاث حالات: تحميل/فراغ/خطأ
- [ ] RTL و(عند إعادة تفعيل الإنجليزية) LTR
- [ ] الوضع الفاتح والداكن + تباين ≥ 4.5:1
- [ ] لا تداخل مع BottomNav/StickyActionBar (شاشة 360px)
- [ ] `aria-label` للأزرار الأيقونية و`aria-pressed` للتبديل
- [ ] `tsc` + `lint` + `test` + `build` ناجحة

## 7) الإنجليزية (إيقاف مؤقت)
العربية فقط في النسخة التجريبية. المفتاح المركزي: `ENGLISH_ENABLED` في `src/lib/i18n.ts` (قيمته `false`).
يؤثر على: اللغة المعروضة في SSR والمتصفح (عبر `getSavedLang` دون تعديل `server.ts`)، زر تبديل اللغة، روابط `hreflang`/`og:locale:alternate`، وخريطة الموقع. القواميس الإنجليزية محفوظة كاملة؛ لإعادة التفعيل: اجعل القيمة `true` وأعد توليد `public/sitemap.xml` (النسخة القديمة محفوظة في Git).

## 8) حالة التطبيق (الجولة الحالية — واجهة فقط، بلا تغيير للباكند)
- ✅ تحويل 66 سطرًا من الخصائص الفيزيائية إلى منطقية مع الحفاظ على شكل العربية (`mr→ms`, `ml→me`, `pr→ps`, `pl→pe`, `right→start`, `left→end`, `text-right→text-start`).
- ✅ تسمية زر الحذف الأيقوني، تبويبات المفضلة (`role=tab`/`aria-selected`)، أهداف لمس 44px للتبويبات والشرائح.
- ✅ استبدال لون `#6366F1` الدخيل بـ `accent-primary`.
- ⏳ متبقٍّ: ترحيل نصوص about/studio/admin/product/profile/bag إلى القواميس، مراجعة التباين في الوضعين على جهاز، المرور على بقية الشاشات بقائمة الفحص (القسم 6).

## 9) أنماط التفاعل (نوافذ منبثقة وجانبية)
| الحاجة | المكوّن | متى |
|---|---|---|
| تأكيد قرار/عملية هدّامة | `ConfirmDialog` | حذف، رفض، تجاهل تغييرات. ممنوع `confirm()` الأصلي |
| تحرير أو تفاصيل أو فلاتر | `SideSheet` | ورقة سفلية على الهاتف، لوحة جانبية من جهة نهاية الصفحة على md+، حبس تركيز + Escape (Radix)، تذييل ثابت للإجراءات |
| اختيار سريع قصير | `BottomSheet` | قوائم قصيرة بلا نموذج |
| تنبيه عابر | `toast` | نجاح/فشل عملية؛ لا يحمل إجراءً حاسمًا |
قواعد: نموذج التحرير داخل `SideSheet` لا داخل القائمة؛ زر الحفظ في `footer`؛ إغلاق النافذة مع تغييرات غير محفوظة يمرّ عبر `ConfirmDialog` (مطبّق في تحرير المنتج).
مطبّق الآن: تعديل منتج التاجر، إدارة صور المنتج، فلاتر المتاجر، قرار شركة التوصيل.

## 10) استوديو التاجر — نمط «الإدارة السريعة»
- **الصف:** `StudioProductRow` — صورة + اسم + سعر + `StockBadge`، تعديل سريع للكمية (`QtyStepper` من 0 إلى 9999)، مفتاح «ظاهر للعملاء» (`role="switch"`)، وإجراءات نصية (تعديل/الصور/حذف) بأهداف لمس 44px.
- **القائمة:** بحث محلي بالاسم/العلامة + شرائح فلترة مع العدّاد (الكل / مخزون منخفض / غير متوفر) — دون استدعاءات إضافية للخادم.
- **التنبيه:** شريط «N منتجات مخزونها منخفض أو نافد» في لوحة المعلومات ينقل مباشرة إلى القائمة مفلترة.
- **التحرير:** `SideSheet` + حماية تغييرات غير محفوظة. العمليات السريعة تُظهر `toast` عند الفشل (لا فشل صامت).
- **قاعدة سلوك:** تعديل الكمية عبر `merchantUpdateOffer` يجعل المنتج متوفرًا تلقائيًا عند الكمية > 0؛ إن كان التاجر قد أخفاه عمدًا يُعاد إخفاؤه حتى لا يظهر دون قصد.
